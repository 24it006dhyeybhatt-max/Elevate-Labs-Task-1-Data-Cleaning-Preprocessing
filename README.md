# Task 1: Data Cleaning & Preprocessing

**AI & ML Internship – Elevate Labs**

## Objective
To learn how to clean, process and prepare raw datasets for Machine Learning applications.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Titanic Dataset containing passenger information.

## Activities Performed
1. Imported and explored the dataset.
2. Identified and handled missing values using Mean, Median and Mode-based imputation.
3. Converted categorical features into numerical values using Label Encoding and One-Hot Encoding.
4. Applied Normalization and Standardization.
5. Visualized and removed potential outliers using Boxplots and the IQR method.

## Project Files
- Google Colab Notebook
- Original Titanic Dataset
- Cleaned Titanic Dataset
- Screenshots of implementation and results

## Conclusion
This task provided practical experience in data cleaning and preprocessing using Python. It helped develop an understanding of missing-value treatment, categorical encoding, feature scaling and outlier detection.
